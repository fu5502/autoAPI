# autoAPI 授权助手

这是一个 Chrome/Edge Manifest V3 扩展，用于把本地浏览器中已经登录的签到站会话同步到 autoAPI，不需要在服务器开启 noVNC。

## 使用

1. 在 autoAPI 后台进入“公益站签到”，对目标站点点击“授权”。
2. 已安装扩展时，后台的“本地授权助手”窗口会自动在当前 Chrome/Edge 配置文件中新开目标站点的登录页。
3. 在新标签页完成登录。登录回跳完成后，扩展会自动读取该站点的 Cookie 和 Local Storage 并同步到 autoAPI。
4. 保持后台“本地授权助手”窗口打开，直至显示“授权同步成功”；通常不需要再次点击扩展。

自动回传未完成时，可在自动打开的登录页中打开扩展并点击“同步当前站点”，扩展会继续当前授权任务。自动唤起不可用时，可展开后台窗口中的“手动同步”备用区域，复制一次性授权码后在扩展弹窗中执行同步。

## 安装

打开 Chrome/Edge 的扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，选择本目录。

扩展代码更新后，在扩展管理页点击“重新加载”后再发起授权；当前版本为 `0.2.1`。

扩展只读取当前标签页所在站点的 Cookie 和 Local Storage，在浏览器端使用 AES-256-GCM 加密后上传。它不保存 Cookie、不读取其他域名数据，授权码 10 分钟有效且只能使用一次。

后台会显示以下状态：

- `正在启动本地授权助手`：后台已向浏览器扩展发起自动授权请求。
- `已打开本地浏览器登录页`：扩展已创建目标站点标签页。
- `等待完成站点登录`：仍停留在登录页，完成登录后会自动检查。
- `助手已连接，等待上传`：扩展已验证站点并领取临时凭据。
- `授权同步成功`：会话快照已加密保存，后续签到会使用它。
- `授权失败`：扩展或服务端会回传具体失败原因；按提示重新生成授权码后重试。

## 故障排查

- 自动授权仅能在安装了扩展的本机 Chrome/Edge 中发起；服务器不需要开启 noVNC。
- 目标站点登录页被关闭后，本次已领取的授权码会失效，需要在后台重新发起授权。
- 当前标签页必须是 `http://` 或 `https://`，并且域名必须与后台授权站点一致。
- 授权码过期、后台重启或授权任务被关闭后，需回到后台重新点击“授权”。
- 若弹窗显示读取失败，请刷新目标站点后再次同步；后台授权弹窗会保留失败原因。
